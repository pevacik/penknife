# Penknife

Веб-приложение в стиле маркетплейса: строка поиска сверху и возможность добавлять карточки товара.

## Стек

- **Frontend**: Vite + React + TypeScript, архитектура [Feature-Sliced Design](https://feature-sliced.design/).
- **Backend**: локальный Express-сервер (позже заменится на удалённый) с хранением в JSON-файле.

## Структура

```
apps/
├── web/       # фронтенд (FSD)
└── server/    # API-сервер
```

## Запуск

```bash
npm install
npm run dev
```

- Frontend: http://localhost:5173
- Backend:  http://localhost:3001

Фронт ходит на бэкенд через Vite-прокси (`/api`). Для удалённого сервера достаточно задать `VITE_API_URL`.

## Возможности

- Строка поиска сверху (ищет по названию, тиражу, тегам, стране и тексту комментариев).
- Сайдбар с фильтрами слева: «Сроки» (Россия/Китай/оба), «Тираж» (подходят изделия с тиражом не больше указанного), «Бюджет» (по цене, сортировка от большего к меньшему).
- Кнопка «Добавить карточку» — создаёт пустую карточку.
- Кнопка «CSV» рядом — окно импорта/экспорта карточек через CSV (колонки: `id`, название, цена, тираж, сделать 50, срок производства, теги). При импорте карточки с существующим `id` обновляются (без дублей), с пустым `id` — создаются заново.
- Клик по карточке открывает страницу `/products/:id`:
  - изображения (несколько, загрузка файлом или по ссылке);
  - поле «Цена» (₽, только цифры);
  - поле «Тираж» (только цифры);
  - поле «Сделать 50» (да/нет, по умолчанию нет);
  - поле «Срок производства» (Китай/Россия, по умолчанию Россия);
  - поле «Теги» (слова через запятую);
  - комментарии с заголовком (отдельная кнопка «Сохранить», удаление по одному);
  - кнопка удаления карточки.

## API

| Метод  | Путь                          | Описание                          |
| ------ | ----------------------------- | --------------------------------- |
| GET    | `/api/products`               | Список карточек                   |
| POST   | `/api/products`               | Создать карточку                  |
| PATCH  | `/api/products/:id`           | Обновить поля карточки            |
| DELETE | `/api/products/:id`           | Удалить карточку                  |
| POST   | `/api/products/:id/comments`  | Добавить комментарий              |
| DELETE | `/api/products/:id/comments/:commentId` | Удалить комментарий     |
| POST   | `/api/products/:id/images`    | Добавить изображение по ссылке    |
| DELETE | `/api/products/:id/images/:imageId` | Удалить изображение       |
| POST   | `/api/uploads` (multipart)    | Загрузить файл изображения        |
| GET    | `/api/health`                 | Проверка работоспособности        |

Данные хранятся в JSON-файле `apps/server/data/products.json`, загруженные изображения — в `apps/server/uploads/` (обе папки создаются автоматически).

## Скрипты

- `npm run dev` — запуск фронта и сервера одновременно.
- `npm run build` — сборка фронта.
- `npm run build:server` — сборка сервера.
- `npm run start` — запуск собранного сервера.
