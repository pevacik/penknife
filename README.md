# Penknife

Веб-приложение в стиле маркетплейса для менеджеров.

## Стек

- **Frontend**: Vite + React + TypeScript, архитектура [Feature-Sliced Design]
- **Backend**: Express-сервер + PostgreSQL (через Prisma ORM).

## Структура

```
apps/
├── web/       # фронтенд (FSD)
└── server/    # API-сервер
```

## Документация

Подробная архитектура, структура кода и руководство по разработке — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Запуск

1. Установить зависимости и поднять базу данных (нужен Docker):

```bash
npm install
docker compose up -d
```

2. Подготовить схему БД (первый раз) и при необходимости импортировать старые данные:

```bash
cd apps/server
npx prisma generate
npx prisma db push
npm run db:import   # необязательно: перенос данных из data/products.json
```

3. Запустить приложение:

```bash
npm run dev
```

- Frontend: http://localhost:5173
- Backend:  http://localhost:3001

Фронт ходит на бэкенд через Vite-прокси (`/api`). Для удалённого сервера достаточно задать `VITE_API_URL`.

## База данных

- PostgreSQL запускается в Docker (`docker-compose.yml`), данные — в volume `penknife_pgdata`.
- Строка подключения задаётся в `apps/server/.env` (`DATABASE_URL`); образец — `apps/server/.env.example`.
- Схема описана в `apps/server/prisma/schema.prisma` (модели `Product`, `ProductImage`, `Comment`, `CommentImage`).
- Загруженные изображения по-прежнему лежат на диске в `apps/server/uploads/`, в БД хранятся только URL.

## Возможности

- Строка поиска сверху (ищет по названию, тиражу, тегам, стране и тексту комментариев).
- Сайдбар с фильтрами слева: «Сроки» (Россия/Китай/оба), «Сделать 50» (Пусто/Да), «Тираж» (подходят изделия с тиражом не больше указанного), «Бюджет» (по цене, сортировка от большего к меньшему).
- Корзина: кнопка «в корзину» на карточке и иконка корзины в шапке. В корзине позиции можно удалять и редактировать комментарий (цена/тираж/срок подставляются автоматически); кнопка «Скачать список» генерирует PDF с первыми картинками и комментариями, после чего корзина очищается.
- Кнопка «Добавить карточку» — создаёт пустую карточку.
- Кнопка «CSV» рядом — окно импорта/экспорта карточек через CSV (разделитель `;`, колонки: `id`, название, цена, тираж, сделать 50, срок производства, теги, изображения, комментарии). При импорте карточки с существующим `id` обновляются (без дублей), с пустым `id` — создаются заново (вместе с изображениями и комментариями).
- Клик по карточке открывает страницу `/products/:id`:
  - изображения (несколько, загрузка файлом, по ссылке или вставкой из буфера обмена); клик по миниатюре открывает просмотр с листанием;
  - поле «Цена» (₽, только цифры);
  - поле «Тираж» (только цифры);
  - поле «Сделать 50» (да/нет, по умолчанию нет);
  - поле «Срок производства» (Китай/Россия, по умолчанию Россия);
  - поле «Теги» (слова через запятую);
  - комментарии с заголовком и изображениями (загрузка файлом или вставкой из буфера обмена, просмотр по клику, удаление по одному);
  - кнопка удаления карточки.

## API

| Метод  | Путь                          | Описание                          |
| ------ | ----------------------------- | --------------------------------- |
| GET    | `/api/products`               | Список карточек (пагинация: `page`, `limit`, `query`, `country`, `circulation`, `maxBudget`, `make50`) |
| GET    | `/api/products/all`           | Все карточки (для CSV-экспорта)   |
| GET    | `/api/products/:id`           | Одна карточка                     |
| POST   | `/api/products`               | Создать карточку                  |
| PATCH  | `/api/products/:id`           | Обновить поля карточки            |
| DELETE | `/api/products/:id`           | Удалить карточку                  |
| POST   | `/api/products/export-pdf`    | PDF с первыми картинками и комментариями (`{ items: [{ id, comment }] }`) |
| POST   | `/api/products/:id/comments`  | Добавить комментарий              |
| DELETE | `/api/products/:id/comments/:commentId` | Удалить комментарий     |
| DELETE | `/api/products/:id/comments/:commentId/images/:imageId` | Удалить изображение комментария |
| POST   | `/api/products/:id/images`    | Добавить изображение по ссылке    |
| DELETE | `/api/products/:id/images/:imageId` | Удалить изображение       |
| POST   | `/api/uploads` (multipart)    | Загрузить файл изображения        |
| GET    | `/api/health`                 | Проверка работоспособности        |

Данные хранятся в PostgreSQL (Docker, БД `penknife`), загруженные изображения — в `apps/server/uploads/` (папка создаётся автоматически).

## Скрипты

- `npm run dev` — запуск фронта и сервера одновременно.
- `npm run build` — сборка фронта.
- `npm run build:server` — сборка сервера.
- `npm run start` — запуск собранного сервера.
- `npm run prisma:generate --workspace server` — генерация Prisma Client.
- `npm run db:push --workspace server` — синхронизировать таблицы со схемой.
- `npm run prisma:migrate --workspace server` — создать/применить миграцию.
- `npm run db:import --workspace server` — импорт данных из `data/products.json`.
